# SCCD-X Engine v2.00

A qualitative structural engine for world politics. Ten capacity components,
eight feedback loops, two forcing blocks — and a provenance tag on every
derived field, because 46 of its parameters carry no value from any source
paper and it says so rather than implying otherwise.

Press the `VI` / `EN` toggle in the corner. The switch re-runs the diagnosis
server-side; every string arrives from the API, and the numbers are asserted
identical across both languages.

**Read the limits before quoting any number.** The v2 outputs are ORDINAL — a
ranking and a threshold-crossing map, not a level. Open the **audit** tab to
see where each number came from.

Source, documentation and the three source papers:
